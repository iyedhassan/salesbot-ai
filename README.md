# SalesBot AI

AI-powered sales chatbot with semantic product search and
Retrieval-Augmented Generation (RAG).

## Project Goals

- Build a responsive chatbot interface.
- Create a REST API with Python and FastAPI.
- Store products and conversations in PostgreSQL.
- Integrate a language model through a backend service.
- Implement semantic search using embeddings and pgvector.
- Add automated tests and Docker support.

## Tech Stack

- Python 3.12+
- FastAPI
- PostgreSQL and pgvector
- SQLAlchemy and Alembic
- React and TypeScript
- Git and GitHub

## Project Status

Currently in the initial setup phase.
